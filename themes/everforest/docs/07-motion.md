# Everforest — Motion

Static X11 tiling (dwm); motion is minimal by design.

## Stance

- **No decorative animation.** Tiling is instant.
- **Compositor (picom):** subtle fades acceptable; keep durations short — the
  soft palette shouldn't be paired with distracting motion.
- **No flashing / strobing.**
- **Reduced-motion friendly** by default (near-zero motion).

Note-level: the theme defines color and type, not animation curves. Compositor
timing lives in the picom config.
