# Everforest — Iconography

Icons come from **Nerd Fonts** glyphs (`Symbols Nerd Font`); this is a
terminal-first rice, not a GTK/icon-theme setup.

## Conventions

- Status bar (dwm) and launcher (rofi) use nerd-font glyphs.
- Color icons by **semantic role** (`warn`/`error`/`info`), else `fg`/`muted`.
- Monochrome glyphs; color carries meaning. No emoji in status output.
- One glyph family across apps for uniform metrics.

Icon shapes are upstream (Nerd Fonts); only their color follows the palette.
