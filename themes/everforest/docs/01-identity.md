# Everforest — Identity

**Concept.** A warm, low-contrast forest: muted greens and soft creams, like
diffuse daylight through a canopy.

**Mood.** Calm, gentle, easy on the eyes for long sessions. Where Purple City is
high-contrast neon, Everforest is soft and restful.

**Polarity.** Dark (the "Dark, Hard" variant).

**Signature.** Green (`base0B`, `#A7C080`) is the accent.

**Provenance.** Sainnhe Park's Everforest. Ported here as a first-class SoT theme
so it derives every app's colors from one palette (it was previously the repo's
default look, hand-copied per app).

**Intended use.** The default fallback theme and the choice for green-leaning
hosts; pairs with the native `everforest` editor colorscheme.
